Solid Result Script Example#

Download the RS3_Result_Scripting_Example folder for this example.

from rs3.RS3Modeler import RS3Modeler
from rs3.results.ResultEnums import SolidsDataType
from rs3.Geometry import Point, Cube
import os

Get the current folder directory.

current_dir = os.path.dirname(os.path.abspath(""))

Specify a port number that is not in use and start the RS3 program.

port = 60501
RS3Modeler.startApplication(port)

Connect with the RS3 Modeler.

modeler = RS3Modeler(port)

For the demonstration purposes only, the model is copied for reuse. You may change the model path to your own model path.

1. Get Node Results#

1.1 Decide which data types you need (optional)#

If you know the data types you want to query, we highly recommend you to specify the data types to optimize the data loading speed. If no data type is specified, all solid data types will be queried.

Here we request Sigma 1 Effective and Total Displacement.

required_data_types = set([
    SolidsDataType.SIGMA_1_EFFECTIVE,
    SolidsDataType.TOTAL_DISPLACEMENT,
])

1.2 Define a box region (optional)#

A cube region is defined by two corners. Only mesh nodes inside or intersecting the box will be returned. If you omit the region in the next step, all nodes in the model would be returned.

solid_query_region = Cube(
    corner1=Point(x=17.0, y=14.5, z=-12.0),
    corner2=Point(x=18.0, y=15.5, z=1.0),
)

1.3 Get the solid results object for a given stage#

getMeshResults returns a list of “SolidResults” (one per stage). Pass the stage number list (e.g. [3, 4, 5]) and the set of data types you need. Then use mesh_results[0], mesh_results[1], mesh_results[2] for each stage.

mesh_results = model.Results.getMeshResults(
    stageNumber=[3, 4, 5],
    requiredDataTypes=required_data_types,
)
mesh_results_stage_3 = mesh_results[0]

1.4 Get node results within the region#

getMeshNodeResults returns a list of node result objects. Each object holds coordinates and the requested result values for one mesh node. includeIntersecting=True means nodes that lie inside OR touch the box are included.

node_results_stage_3 = mesh_results_stage_3.getMeshNodeResults(
    region=solid_query_region,
    includeIntersecting=True,
)

1.5 Read values from one node (by position in the list)#

The list is indexed from 0. Here we take the first node (index 0) and read its coordinates and the two requested result types.

node_index = 0
one_node_s3 = node_results_stage_3[node_index]
node_id_s3 = one_node_s3.NodeID
x_coord_s3 = one_node_s3.XCoordinate
y_coord_s3 = one_node_s3.YCoordinate
z_coord_s3 = one_node_s3.ZCoordinate
sigma1_s3 = one_node_s3.getResult(SolidsDataType.SIGMA_1_EFFECTIVE)
total_disp_s3 = one_node_s3.getResult(SolidsDataType.TOTAL_DISPLACEMENT)
print(f"Solid Stage 3, node ID {node_id_s3}: \n"
      f"(x, y, z, Sigma1 Effective, Total Displacement) = "
      f"({x_coord_s3}, {y_coord_s3}, {z_coord_s3}, {sigma1_s3}, {total_disp_s3})"
)

2. Element Results#

2.1 Define a box region (optional)#

Create a box region near the tunnel by defining two corners.

solid_tunnel_query_region = Cube(
    corner1=Point(x=10.5, y=5.0, z=-10.0),
    corner2=Point(x=11.0, y=6.0, z=-9.0),
)

2.2 Get element results within the region#

getMeshElementResults returns a list of element result objects. Each object holds attached node IDs and yield element information

element_results_stage_3 = mesh_results_stage_3.getMeshElementResults(
    region=solid_tunnel_query_region,
    includeIntersecting=True,
)

2.3 Get all yielded elements that have failure points.#

yield_elements_s3 = [item for item in element_results_stage_3 if item.YieldingResults.getFailurePoints()]

2.4 Get the first yielded element in the list.#

yield_element_index = 0
one_element_s3 = yield_elements_s3[yield_element_index]
element_id_s3 = one_element_s3.ElementID
attached_node_ids_s3 = one_element_s3.AttachedNodes
failure_point_s3 = one_element_s3.YieldingResults.getFailurePoints()
num_failure_points_s3 = len(failure_point_s3)
yield_percent_s3 = one_element_s3.YieldPercent

failure_info = []

for i, fp in enumerate(failure_point_s3, start=1):
    failure_info.append(
        f"{i}. "
        f"Coord=({fp.XCoordinate}, {fp.YCoordinate}, {fp.ZCoordinate}), "
        f"Type={fp.FailureTypes}, "
        f"Yield Percentage={yield_percent_s3}"
    )

print(
    f"Solid Stage 3, element ID {element_id_s3} "
    f"with attached node ids {attached_node_ids_s3} "
    f"has {num_failure_points_s3} failure point(s):\n"
    + "\n".join(failure_info)
)
